# 🚀 AI Career Roadmap

A modern, responsive and interactive **Career Learning Roadmap Dashboard** built with **React + Tailwind CSS**.  
This project helps users choose a career path, follow structured learning roadmaps, track progress, and stay motivated through gamification.

## 🎯 Features

- 🎨 Modern SaaS UI/UX Design
- 🌙 Dark Mode Interface
- 📱 Fully Responsive (Mobile / Tablet / Desktop)
- 🧭 Multi-page Navigation (React Router)
- 📊 Roadmap Progress Tracking UI
- 🏆 Achievement System (Gamification UI)
- ⚡ Fast & Lightweight Performance
- 🧩 Component-based Architecture
- 🎯 Career Path Selection System

---

## 🛠 Tech Stack

- ⚛️ React (Vite)
- 🎨 Tailwind CSS
- 🔀 React Router DOM
- 🧠 Lucide Icons (or SVG icons)
- 💡 JavaScript (ES6+)
